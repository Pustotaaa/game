# Бездна 100

## [▶ Открыть игру](https://pustotaaa.github.io/game/)

Браузерная игра: лагерь, питомцы и десять этажей бездны.

Исходники игры находятся в папке [`dist`](dist).

## Публикация

Игра опубликована на GitHub Pages: https://pustotaaa.github.io/game/

Публикация настроена из ветки `main`, папка `/(root)`. Корневая страница автоматически открывает игру из папки `dist`.

## Лесное убежище

Лагерь нарисован в 2D на Canvas: негустой лес, ручей с мостиком и воронка в земле. Нажмите на тропинку для движения или на постройку, чтобы подойти и открыть её меню. На клавиатуре: WASD / стрелки для ходьбы, E для взаимодействия рядом с объектом. Ручей пересекается по мосту; постройки и воронка непроходимы. Выбор этажа запускает анимацию спуска, после которой начинается бой.

Новая иллюстрация лагеря создана кодом в `dist/forest-camp.js`, без внешних ассетов. Боевые этажи и сохранения используют прежние системы.

Проверка логики: `node --test tests/gameplay.test.cjs`.

## 3D-версия для Windows · ветка voxel-godot

Проект Godot 4.7.2+ находится в [`godot/`](godot/README.md): лесной лагерь, объёмные модели в формате MagicaVoxel `.vox`, вращаемая камера и боевые этажи 2–4. Готовый Windows ZIP собирается workflow **Voxel Windows** и доступен в его артефактах. Этажи 5–10 и опубликованная браузерная версия в `main` не изменяются.
