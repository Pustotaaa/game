# Бездна 100

## [▶ Открыть игру](https://abyss-five-ruins-k8m2.lavishcoil.chatgpt.site)

Браузерная игра: лагерь, питомцы и десять этажей бездны.

Исходники игры находятся в папке [`dist`](dist).

## GitHub Pages

Стартовая страница и файл `.nojekyll` уже подготовлены.

Чтобы включить публикацию, откройте [Settings → Pages](https://github.com/Pustotaaa/game/settings/pages), затем выберите:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

Нажмите **Save**. После завершения публикации игра будет доступна по адресу:

https://pustotaaa.github.io/game/

Корневая страница автоматически открывает игру из папки `dist`.
