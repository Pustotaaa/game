# Бездна 100

## [▶ Открыть игру](https://pustotaaa.github.io/game/)

Браузерная игра: лагерь, питомцы и десять этажей бездны.

Исходники игры находятся в папке [`dist`](dist).

## Публикация

Игра опубликована на GitHub Pages: https://pustotaaa.github.io/game/

Публикация настроена из ветки `main`, папка `/(root)`. Корневая страница автоматически открывает игру из папки `dist`.
